# مرصاد — النسخة التجريبية

منصة عربية RTL لإدارة المخاطر والقرارات القانونية للشركات، تشمل إدارة الموظفين والعقود وطلبات المراجعة القانونية ولوحة الإدارة.

## محتويات النسخة
- إضافة الموظفين وتعديلهم وأرشفتهم واستعادتهم وربط مستنداتهم وتحليلاتهم.
- تحليل قرارات إنهاء علاقة موظف وتوقيع عقد مورد.
- رفع عقود PDF وWord وعرض نتائج تجريبية محددة مسبقًا.
- طلب مراجعة قانونية مع المرفقات وسجل انتقالات الحالة.
- لوحة إدارة الشركات والطلبات والمستندات.

التحليل محاكاة للعرض وليس ذكاء اصطناعيًا متصلًا. التسجيل والبيانات والمرفقات في النسخة المنشورة تعمل عبر الخادم.

## التقنيات
React 19، TypeScript، Vinext/Vite، Tailwind، Cloudflare Workers، D1/SQLite وR2. تعريف قاعدة البيانات في db/schema.ts والترحيل الأول في drizzle/.

## رفع الكود إلى GitHub
فك الضغط، ثم ارفع محتويات مجلد mirsad إلى مستودعك. احرص على تضمين ملفات الإعداد المخفية وملف pnpm-lock.yaml. لا ترفع ملفات .env أو .dev.vars أو node_modules أو بيانات قاعدة التشغيل.

يمكنك أيضًا تنفيذ هذه الأوامر داخل المجلد بعد إنشاء مستودع فارغ في GitHub:

```sh
git init
git add .
git commit -m "Initial Mirsad prototype"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

## التشغيل المحلي
تحتاج Node.js >=22.13.0 وpnpm بالإصدار المحدد في package.json.

```sh
pnpm install --frozen-lockfile
pnpm build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_glamorous_micromacro.sql
pnpm dev
```

طبّق ملف الترحيل مرة واحدة فقط على قاعدة محلية جديدة. افتح العنوان الذي يعرضه أمر التشغيل. النسخة المحلية النظيفة تستخدم وضع portable، وفيه محاكاة تسجيل دخول على loopback للتطوير فقط. هذه المحاكاة ليست جزءًا من مصادقة الإنتاج.

لدخول الإدارة محليًا، أنشئ ملف .dev.vars غير المتعقب في Git، واضبط ADMIN_ACCESS_CODE على رمز محلي تختاره. في الإنتاج اضبط القيمة عبر أسرار مزود الاستضافة؛ لا تضعها في الكود.

## النشر خارج الاستضافة الحالية
رفع الكود إلى GitHub يحفظ المصدر، لكنه لا ينشر التطبيق تلقائيًا. التطبيق يحتاج خادمًا وقاعدة بيانات وتخزين ملفات؛ لا يعمل بكامل وظائفه على GitHub Pages كصفحات ثابتة.

النسخة الحالية تعتمد على مصادقة ChatGPT التي توفرها استضافة Sites، وعلى ربط DB وBUCKET. عند نقلها لاستضافة أخرى يجب إعداد Workers وD1 وR2، تطبيق الترحيلات، وضبط ADMIN_ACCESS_CODE، واستبدال مصادقة app/chatgpt-auth.ts بمصادقة موثوقة مناسبة أو بوابة موثوقة تتحقق من الهوية. لا تثق برؤوس oai-authenticated-* الواردة مباشرة من مستخدم الإنترنت. رمز الإدارة وحده ليس بديلًا عن تسجيل الدخول.

يحتفظ .openai/hosting.json بربط الموقع الأصلي؛ معرّف الموقع ليس مفتاحًا سريًا. لا تستخدم الربط لنشر مشروع مستقل دون إعداد استضافته الخاصة.

## ما لا يتضمنه الملف
لا يحتوي على كلمات مرور الإنتاج أو جلسات المستخدمين أو ملفات العملاء أو نسخة بيانات الإنتاج أو node_modules أو ملفات البناء. يحتوي على الكود والمخطط والترحيلات والأصول وتعليمات التشغيل. بيانات العرض الافتراضية موجودة في الكود وتُنشأ داخل مساحة المستخدم عند اختيار الشركة التجريبية.
